# LoRA Training Details

## Overview

The SFX LoRA adapter fine-tunes MOSS-Audio-8B-Instruct for sound event detection with timestamps. It replaces the generic "describe this audio" capability with structured, timestamped sound event predictions.

## Model Card

| Parameter | Value |
|-----------|-------|
| **Base model** | `OpenMOSS-Team/MOSS-Audio-8B-Instruct` |
| **LoRA rank** | 128 |
| **LoRA alpha** | 256 |
| **Target modules** | All linear layers |
| **Training samples** | 10,998 unique soundscapes |
| **Epochs** | 2 (best at step 2750) |
| **Eval loss** | 2.76 |
| **Adapter size** | ~667 MB |
| **HuggingFace repo** | `LAION-AI/moss-audio-sfx-lora-v4` |

## Training Data

- **Source**: LAION soundscapes dataset
- **Annotations**: Generated by Gemini 2.5 Pro
- **Format**: Each sample contains an audio file and a JSON annotation with timestamped sound events
- **Prompt template**: "Please describe all audio events in this audio together with start time, end time, and caption for {segment_duration} segments that are {overlapping_str}."
- **Variations**: Training includes short/medium and overlapping/non-overlapping combinations

## Training Configuration

```yaml
# Key training parameters
per_device_train_batch_size: 1
gradient_accumulation_steps: 8
learning_rate: 2e-4
lr_scheduler_type: cosine
warmup_steps: 100
max_steps: 5500  # ~2 epochs
bf16: true
gradient_checkpointing: true

# LoRA configuration
lora_r: 128
lora_alpha: 256
lora_dropout: 0.05
target_modules: all linear
```

## Inference

The LoRA adapter is merged into the base model at inference time for maximum speed:

```python
from peft import PeftModel

# Load base model
model = MossAudioModel.from_pretrained(
    "OpenMOSS-Team/MOSS-Audio-8B-Instruct",
    dtype=torch.bfloat16,
    device_map="cuda:0",
)

# Load and merge LoRA
model = PeftModel.from_pretrained(model, "LAION-AI/moss-audio-sfx-lora-v4")
model = model.merge_and_unload()
model.eval()
```

## Best Prompt Configuration

After testing all 4 combinations of segment_duration x overlapping:

| Configuration | Typical Events/Scene |
|--------------|---------------------|
| short, non-overlapping | 8-12 events |
| short, overlapping | 10-15 events |
| medium, non-overlapping | 5-8 events |
| **medium, overlapping** | **6-10 events** |

**medium_overlap** is the recommended configuration. It produces broader predictions that the downstream MOSS-Audio-8B-Thinking model can refine into specific events.
